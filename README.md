# No Capes

Hides Helldiver capes in HELLDIVERS (2015), for the [Obsidian](https://github.com/Alomare/ObsidianLauncher) mod manager.

## What it does

- Hides capes on every Helldiver: you, other players and bots.
- Works on the ship and in missions, including capes picked in the Armory mid-session.
- Capes stay hidden when other mods try to show them, such as the Cape toggle in Photo Mode.

## Option

- **Hide capes** (on by default): turns capes off and on. Set it in Obsidian, or in game from the pause menu under **Mods**. Changes in game apply at once.

## Playing with others

A client mod: it changes only what you see. Other players see capes as usual, and joining any lobby works as without the mod.

Needs Obsidian API. The pause menu row needs Obsidian API 1.16.0 or later.
