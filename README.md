# No Capes

A mod for HELLDIVERS (2015) that hides Helldiver capes, for [Obsidian Mod Manager](https://github.com/Alomare/ObsidianModManager).

## What it does

- Hides the cape of every Helldiver: the player, other players and bots.
- Works on the ship and in missions, including capes picked in the Armory mid-session.
- Capes stay hidden when another mod tries to show them, such as the Cape toggle in Photo Mode.

## Option

- **Hide capes** (on by default): switches capes off and on. Set it in Obsidian, or in game from the pause menu under **Mods**. A change in game applies at once.

## Playing with others

A client mod: it changes only what this player sees. Other players see capes as usual, and joining any lobby works the same as without the mod.

Needs Obsidian API. The pause menu row needs Obsidian API 1.16.0 or later.
